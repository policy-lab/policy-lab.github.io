Como usar este painel

Para quem é

Este painel é voltado a gestores públicos, equipes de monitoramento e avaliação, imprensa e quem acompanha políticas públicas no Brasil. Reúne um conjunto selecionado de estatísticas-chave, a partir de fontes oficiais, para dar um panorama rápido de cada área.

O que ele é, e o que não é

O painel não pretende ser exaustivo. Não reproduz todas as estatísticas de cada tema nem substitui os sistemas oficiais (DATASUS, INEP, Siconfi, SNIS, entre outros). A proposta é funcionar como porta de entrada: mostra a estatística, a tendência e a fonte, e leva direto ao sistema de origem quando você precisa aprofundar.

Como se encaixa

Acompanha o Guia de Fontes de Dados do FGV CLEAR. Para cada estatística, o link da fonte oficial está sempre na ficha.

Para navegar: clique em qualquer card para abrir a ficha completa, com a série histórica, os recortes por UF e região e a fonte. Use os filtros de área no topo para focar num tema.

O painel é de monitoramento, não de tempo real. A maioria das estatísticas é anual e sai em meses previsíveis, então uma revisão por trimestre (janeiro, abril, julho e outubro) cobre o painel inteiro.

Os meses são indicativos, baseados na última divulgação observada de cada fonte. Calendários oficiais mudam de ano para ano; reconfirme sempre na página da fonte.

  • As estatísticas vêm de fontes oficiais brasileiras (IBGE, INEP, DATASUS, Tesouro Nacional/Siconfi, MDS, INPE, entre outras). Cada valor traz a fonte e a data da última divulgação.
  • O painel é de monitoramento, não de tempo real. Os valores refletem a última divulgação de cada fonte e podem estar defasados frente ao dado mais recente.
  • Os meses do calendário são indicativos. Reconfirme sempre na página oficial antes de tratar uma estatística como atrasada.
  • O painel não substitui a análise técnica nem a leitura da metodologia de cada fonte. Para uso em avaliação, cite a fonte primária.
